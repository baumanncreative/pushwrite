# PushWrite icon assets

Three original directions were prepared under `IconConcepts/`:

1. `01-wave-to-cursor.svg`: waveform resolving into an insertion cursor
2. `02-microphone-cursor.svg`: microphone combined with a cursor
3. `03-speech-arrow.svg`: speech shape with an insertion arrow

Direction 1 was selected because it communicates both speech and text insertion at 16–18 px without depending on a generic microphone silhouette. `PushWriteMenuBarTemplate.svg` is monochrome and marked as a template image at runtime, so macOS controls Light/Dark rendering. `PushWrite.iconset` contains all required 16–1024 px representations; `PushWrite.icns` is generated by `scripts/build_pushwrite_icon.swift` and bundled as the app icon.

The design uses no external proprietary asset. The app UI uses system fonts. The mark remains monochrome in the menu bar; it does not force the company accent red against macOS conventions.
