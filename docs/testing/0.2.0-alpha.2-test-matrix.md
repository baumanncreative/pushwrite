## Manueller Systemkontakt

Die veröffentlichte Vorversion wurde nach einem LaunchServices-Neustart mit real erteilter Mikrofonfreigabe erfolgreich aufgenommen, lokal transkribiert und in TextEdit eingefügt. Der Alpha.2-Kandidat ergänzt deterministische Tests für die aktualisierte Menüanzeige und die Berechtigungsaktion. Die abschliessenden Alpha.2-LaunchServices-Läufe werden auf dem konkreten Release-Bundle protokolliert.

- Developer-ID-, Gatekeeper- und Notarisierungsprüfung einer öffentlich vertrauenswürdigen Signatur ist ohne lokale Developer-ID-Identität nicht möglich.
- Intel-Macs sind nicht Teil dieser Alpha.
