# PushWrite 0.3.0 — test matrix

Date: 2026-08-02

| Gate | Expected evidence |
|---|---|
| Core language logic | `./scripts/run_pushwrite_unit_tests.sh` |
| Settings catalogue and menu refresh | `./scripts/run_pushwrite_ui_tests.sh` |
| Swift typecheck | AppKit/AVFoundation build through `build_pushwrite_product.sh` |
| Local runtime build | pinned `llama.cpp` b10227, static `llama-completion`, no repository-local dynamic dependency |
| Model integrity | exact Whisper and Qwen model size and hashes at fetch, product build, runtime and extracted-install checks |
| Swiss German → Hochdeutsch | `./scripts/run_swiss_german_asr_validation.sh` evaluates five pinned Swiss Parliaments Corpus samples with explicit Whisper automatic language detection and requires aggregate WER ≤ 0.40 |
| Swiss German → English | Swiss German recognition uses the German written transcript; the local German-to-English direction is covered by `./scripts/run_local_text_transformation_validation.sh` |
| English → Spanish/French | required semantic terms in local quality validation |
| Offline behavior | Whisper has no network dependency; text runtime uses `--offline` and passes quality validation under `(deny network*)` |
| Product regression | existing unit, UI, recording, transcription/insertion and app compatibility validations |
| Packaging | fresh native runtimes, ad-hoc-signed app structure, explicitly suffixed unsigned ZIP and DMG below GitHub's 2 GiB per-file limit, SHA-256 sums, release metadata and GitHub Actions/Sigstore provenance attestations |
| Installability | extract release ZIP, verify app identity/ad-hoc signature/entitlement/models, launch through LaunchServices; document the expected Gatekeeper override for an internet download |
| Security | `docs/security/0.3.0-security-review.md` and GitHub Actions |

The Swiss German evaluation downloads only public test fixtures during validation. The shipped app and both bundled inference runtimes remain fully offline and contain no dataset material.

## Release decision

The matrix is considered passed only when all commands complete on the exact release commit, the GitHub checks are green, downloaded release assets match the published `SHA256SUMS.txt`, the immutable release and source-bound GitHub attestations verify, and the install validator passes against the published artifact.
