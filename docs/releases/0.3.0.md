# PushWrite 0.3.0

Release date: 2026-08-10

## Added

- independent spoken-language and output-language settings;
- input modes for automatic detection, German (Germany), German (Austria), German (Switzerland/Swiss German), English, Spanish and French;
- output modes for System, German, English, Spanish and French;
- stronger Swiss German recognition and Hochdeutsch output with bundled Whisper Large-v3 Q5_0;
- fully local translation between the supported languages using bundled `llama.cpp` and Qwen2.5 1.5B Instruct;
- model checksum, model size, license, offline-runtime and OS network-denial controls;
- release validation for local language quality, app packaging and extracted installation artifacts.

## Privacy

No API key is needed. Audio and text are not sent to a service. There is no Cloud fallback, telemetry or clipboard monitor. Production audio, Whisper JSON and local-model prompts remain in memory and cross child-process boundaries only through pipes. The local text subprocess is prevented from opening network connections by a macOS sandbox profile.

## Distribution

The ARM64 ZIP and DMG contain the application and both model runtimes, so they are substantially larger than the 0.2 Alpha artifacts. They target macOS 13 or newer. Public stable artifacts are produced only with the reviewed Developer ID Application identity, exact Team-ID verification, Apple notarization and stapling. Ad-hoc builds are development-only and are not publishable.

## Known limits

- Apple Silicon only;
- automatic recognition distinguishes supported base languages; explicit Swiss German constrains Whisper to German;
- short push-to-talk dictation is the tested use case; input above 20,000 characters is rejected;
- small local models can still mistranslate uncommon names, dialect expressions or specialist terminology;
- Developer ID signing and notarization depend on external credentials not stored in this repository.
