# PushWrite 0.3.0

Release date: 2026-08-10

## Added

- independent spoken-language and output-language settings;
- input modes for automatic detection, German (Germany), German (Austria), German (Switzerland/Swiss German), English, Spanish and French;
- output modes for System, German, English, Spanish and French;
- stronger Swiss German recognition and Hochdeutsch output with bundled Whisper Large-v3 Q5_0;
- fully local translation between the supported languages using bundled `llama.cpp` and Qwen2.5 1.5B Instruct;
- model checksum, model size, license, offline-runtime and OS network-denial controls;
- release validation for local language quality, app packaging and extracted installation artifacts.

## Privacy

No API key is needed. Audio and text are not sent to a service. There is no Cloud fallback, telemetry or clipboard monitor. Production audio, Whisper JSON and local-model prompts remain in memory and cross child-process boundaries only through pipes. The local text subprocess is prevented from opening network connections by a macOS sandbox profile.

## Distribution

The ARM64 ZIP and DMG contain the application and both model runtimes, so they are substantially larger than the 0.2 Alpha artifacts. They target macOS 13 or newer.

The GitHub direct-download artifacts are explicitly suffixed `-unsigned`. They are ad-hoc signed for code-structure verification but have no Apple Developer ID and are not notarized. macOS may therefore require the user to approve the first launch with **Open Anyway** in System Settings → Privacy & Security.

GitHub Actions builds the artifacts from the tagged commit and publishes Sigstore-backed build-provenance attestations. Release immutability prevents later replacement of the tag or assets. Bind a downloaded file to this exact release with `gh release verify-asset v0.3.0 FILE -R baumanncreative/pushwrite`, then verify its build origin with `gh attestation verify FILE -R baumanncreative/pushwrite --signer-workflow baumanncreative/pushwrite/.github/workflows/release.yml --source-ref refs/heads/main`. SHA-256 checksums, build metadata and extracted-install validation are also published with the application.

The separate authenticated release workflow remains available for future Developer ID signing, exact Team-ID verification, Apple notarization and stapling.

## Known limits

- Apple Silicon only;
- automatic recognition distinguishes supported base languages; explicit Swiss German constrains Whisper to German;
- short push-to-talk dictation is the tested use case; input above 20,000 characters is rejected;
- small local models can still mistranslate uncommon names, dialect expressions or specialist terminology;
- the GitHub direct-download artifact is not Apple-notarized and may require a manual Gatekeeper override;
- Developer ID signing and notarization remain unavailable until external credentials are configured outside this repository.
