# PushWrite 0.3.2

PushWrite 0.3.2 redesigns the menu-bar experience and makes launch and replacement behaviour explicit.

## What changed

- Replaced the traditional menu with the selected compact status popover.
- Added live recording duration, audio level, workflow state, language summary and permission status.
- Applied the baumanncreative palette and typography rules from the company handbook.
- Kept the red top-right gear as the only settings entry point.
- Moved `PushWrite beenden` to the bottom-left action position.
- Opens the status popover on launch and presents startup failures visibly.
- Reuses one running instance and blocks parallel installations from sharing the microphone, global shortcut or runtime directory.
- Documents and validates a clean app-bundle replacement instead of copying over an existing bundle.

The workflow visualization remains included in 0.3.2 and can be reconsidered in a later release.

## Installation gate

Quit every running PushWrite instance, move the existing `/Applications/PushWrite.app` to Trash, and then copy the new app into `/Applications`. Keep `~/Library/Application Support/PushWrite` to preserve local settings and state.

An authenticated stable artifact must be Developer-ID signed, notarized and stapled. If an explicitly acknowledged unsigned fallback is published, its filename and metadata identify that state and macOS requires the documented one-time Gatekeeper exception.
