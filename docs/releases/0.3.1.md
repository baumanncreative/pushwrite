- `INSTALLIEREN.txt` is included directly in the DMG and describes the complete Gatekeeper override sequence for distribution without Apple Developer ID.

## Installation without Apple Developer ID

The ZIP and DMG are explicitly suffixed `-unsigned`. They are ad-hoc signed for code-structure verification but have no Apple Developer ID and are not notarized. This means the normal identified-developer launch dialog is technically unavailable.

After dragging PushWrite to Applications, start it once and choose **Done** in the warning that offers **Move to Trash** or **Done**. Then open System Settings → Privacy & Security, choose **Open Anyway** for PushWrite and confirm **Open**. Apple makes this override available for about one hour after the blocked launch attempt.

GitHub Actions builds the artifacts from the tagged commit and publishes Sigstore-backed build-provenance attestations. Release immutability prevents later replacement of the tag or assets. Bind a downloaded file to this exact release with `gh release verify-asset v0.3.1 FILE -R baumanncreative/pushwrite`, then verify its build origin with `gh attestation verify FILE -R baumanncreative/pushwrite --signer-workflow baumanncreative/pushwrite/.github/workflows/release.yml --source-ref refs/heads/main`.

## Unchanged limits

- Apple Silicon and macOS 13 or newer only.
- Developer ID signing and notarization remain unavailable until external Apple Developer Program credentials are configured outside this repository.
- Recognition and local text processing remain fully offline; no API key is required.
